Flash EQ-Linear · demos

See the speedup

Flash EQ-Linear computes rotation-equivariant linear layers in the group Fourier domain: fewer multiplications, the same outputs. Two interactive pages explain and replay the paper's measurements; two recordings show real runs on RTX 4090 GPUs.

S2

How it works

A five-step animation: the circulant matrix of an equivariant layer, the Fourier transform that makes it diagonal, conjugate symmetry, and the inverse transform that returns the same result. Change the group size T to see the bound grow.

Live terminal race

Naive EQ-ViT-H on one GPU and Flash EQ-ViT-H on another start together and push the same 3,200 images through the network (FP32, batch 128, 224 × 224).

  • 1.69× faster: 13.3 s vs. 22.5 s
  • Measured 142 → 241 img/s; paper Table 3: 139 → 232 img/s

R2

Super-resolution, patch by patch

Naive and Flash EQ-SwinIR-LIIF upscale the same image ×2 as 294 low-resolution patches of 48 × 48 (batch 1, FP32, the paper's Table 4 setting). A patch turns sharp when the network finished it in the recorded run.

  • 1.24× faster: 10.5 s vs. 13.0 s; paper Table 4: 1.26×
  • The picture is the reference high-resolution image: the networks use random weights, so only the timings are real.

At batch 1 this server's CPU limits the launch rate, so absolute times are longer than in Table 4; the ratio is unaffected.
