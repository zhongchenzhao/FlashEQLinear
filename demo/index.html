Flash EQ-Linear · demos

See the speedup

Flash EQ-Linear computes rotation-equivariant linear layers in the group Fourier domain: fewer multiplications, the same outputs. Two interactive pages explain and replay the paper's measurements; two recordings show real runs on RTX 4090 GPUs.

How it works

A five-step animation: the circulant matrix of an equivariant layer, the Fourier transform that makes it diagonal, conjugate symmetry, and the inverse transform that returns the same result. Change the group size T to see the bound grow.

Real runs and real outputs

Each race puts a standard network next to its naive and Flash equivariant versions on RTX 4090 GPUs.

R1

Live terminal race

Standard ViT-H, naive EQ-ViT-H and Flash EQ-ViT-H each get a GPU, start together and push the same 3,200 images through the network (FP32, batch 128, 224 × 224).

  • Flash 1.69× faster than ViT-H and 1.66× faster than naive EQ-ViT-H: 13.4 s vs. 22.5 s and 22.2 s
  • Naive EQ-ViT-H matches ViT-H (1.01×) with 4.0× fewer parameters. Measured 142 / 144 / 240 img/s; paper Table 3: 139 / 139 / 232.

R2

Super-resolution race, patch by patch

SwinIR-LIIF, naive EQ-SwinIR-LIIF and Flash EQ-SwinIR-LIIF upscale the same image ×2 as 294 patches of 48 × 48, 16 per batch (FP32). Patches turn sharp when their batch finished in the recorded run.

  • Flash 1.25× faster than SwinIR-LIIF and 1.29× faster than naive EQ: 2.16 s vs. 2.71 s and 2.79 s
  • Naive EQ runs at 0.97× the speed of SwinIR-LIIF with 3.9× fewer parameters. The picture is the reference image (random weights), played 4× slower.

At batch 1 this server's CPU limits kernel launches and hides the arithmetic savings, so the recording uses batches of 16 to keep the GPU busy.

R3

Quality: what equivariance adds

Real ×2 outputs of trained MambaIR and EQ-MambaIR on Urban100 img039. The red box marks the striped facade next to the 5F sign: MambaIR blurs the stripes and EQ-MambaIR recovers them.

  • +0.64 dB on the whole image and +6.4 dB inside the box (Y-PSNR against the ground truth)
  • Flash EQ-Linear computes the same equivariant layers, so Flash EQ-MambaIR produces this same image (largest difference 9e-6 in an FP32 check).
